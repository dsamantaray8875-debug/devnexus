# DevNexus — Enterprise Cloud DevOps Platform on AWS

DevNexus is a production-style cloud-native DevOps platform built on AWS.

## Architecture

Developer
   ↓
GitHub
   ↓
CI/CD
   ↓
Docker
   ↓
Amazon ECR
   ↓
Amazon EKS
   ↓
Microservices
   ↓
AWS Services
   ↓
Prometheus + Grafana + EFK
